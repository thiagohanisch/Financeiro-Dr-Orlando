# FinTrack Orlando — versão individual

1. Publique `firebase-rules.json` em Firebase > Realtime Database > Regras.
2. Envie `index.html` para a raiz de um repositório GitHub novo.
3. Em Settings > Pages, selecione Deploy from a branch, `main`, `/(root)`.
4. No Firebase Authentication, mantenha E-mail/Senha ativo e autorize o domínio `thiagohanisch.github.io`.
5. Entre com `orlando20003am@gmail.com` e a senha cadastrada no Firebase.

A aplicação lê e grava em `/fintrack` e aceita somente o UID autorizado.
